# Полный просмотр Menarium (без Docker и без ручной настройки)

Одна команда поднимает базу, demo-данные и сайт. **Вам ничего настраивать не нужно.**

## Запуск

```powershell
cd C:\Users\mks\Desktop\menarium-2
npm run preview:full
```

Дождитесь строки `Full preview is ready`, затем откройте **http://localhost:3000**

Остановка: `Ctrl+C` в том же окне терминала.

## Маршрут полной приёмки UI

| # | URL | Что смотреть |
|---|-----|--------------|
| 1 | `/` | Главная, hero, live-карточки |
| 2 | `/catalog` | Фильтры, сортировка, сетка |
| 3 | `/swipe` | Свайп-карточка и кнопки |
| 4 | `/item/…` | Галерея, обмен, чат |
| 5 | `/new` | Создание объявления |
| 6 | `/exchange` | Вкладки обменов, чат сделки |
| 7 | `/profile` | Статистика, быстрые ссылки |
| 8 | `/notifications` | Уведомления |
| 9 | `/my-items` | Свои объявления |
| 10 | `/profile/chats` | Чаты |

## Маршрут приёмки логики

1. Maria → `/new` → объявление с фото  
2. Dmitry → карточка Maria → предложить обмен  
3. Maria → `/exchange` → принять → чат  
4. Обе стороны → завершить обмен  
5. Проверить уведомления, редактирование, отклонение/отмену  
6. `/swipe` → пропуск карточки не возвращает её
